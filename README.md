## Proyectos

### 🌧️ [ClimApp](https://github.com/juanmorar/ClimApp)

Pronóstico del clima para Coronel que además **mide qué tan bien le achunta cada modelo**. Guarda todos los días lo que predijo cada fuente, lo compara con lo que realmente pasó, y arma un historial de exactitud para un punto geográfico específico.

La gracia está en el esquema de datos, guarda la anticipación de cada pronóstico, porque un modelo puede ser excelente a 2 días y puro ruido a 8.

`Python` · `JavaScript` · `SQLite` · `Open-Meteo API`

### ⚖️ [LeyAI](https://github.com/juanmorar/LeyAI) · [ver demo](https://ley-ai.vercel.app)

Asistente para consultar y comparar legislación de cooperativas de 15 países, con búsqueda semántica sobre el texto completo de cada ley.

Es un **RAG construido desde cero**, sin LangChain. El troceo respeta los artículos en vez de cortar cada N caracteres, así las citas sirven. La versión anterior leía solo el 2% de la ley canadiense; esta cubre el 100% de las 15.

`Python` · `FastAPI` · `React` · `Vite` · `Tailwind` · `Google Cloud Run`
